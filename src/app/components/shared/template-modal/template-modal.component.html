{{ variable }} Nenhuma variável identificada
As variáveis são identificadas automaticamente no formato {{ "{VARIAVEL}" }}

Como usar variáveis no template:

  • {{ "{CLIENTE_NOME}" }} - Nome do cliente
  • {{ "{CLIENTE_EMAIL}" }} - Email do cliente
  • {{ "{VALOR_TOTAL}" }} - Valor total da proposta
  • {{ "{SERVICOS}" }} - Lista de serviços
  • {{ "{PRAZO_ENTREGA}" }} - Prazo de entrega
  • {{ "{DATA_ATUAL}" }} - Data atual

Dica: Use as variáveis entre chaves no seu documento Word para substituição automática.
